Supabase Database Setup Guide
Follow these 2 quick steps to link your live Supabase project.

Step 1: Run the Database Schema SQL
Open your Supabase Project Dashboard → SQL Editor → Click New query → Paste the contents of supabase_schema.sql and click Run.

Step 2: Connect Your API Keys in supabase-config.js
Open your Supabase Project Settings → API → Copy Project URL & anon public key into:

window.NAMORA_SUPABASE_CONFIG = {
  SUPABASE_URL: "https://your-project.supabase.co",
  SUPABASE_ANON_KEY: "eyJhbGciOi..."
};
